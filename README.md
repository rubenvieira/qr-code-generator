# QR Code Generator - Command Center

![Command Center](https://img.shields.io/badge/Status-Active-success)
![Design](https://img.shields.io/badge/Aesthetic-Retro%20%2F%20CRT-blueviolet)

A beautiful, modern, and high-tech utility to generate custom QR Codes easily. Built with a unique dual-theme design system that embraces both tactile physical hardware and glowing phosphor screens.

## 🎨 Dual-Theme Design Aesthetic

The application is built around a comprehensive and immersive design system:

*   ☀️ **Light Mode ("Day Shift" Instrument Panel):** Tactile, physical hardware with inset panels, raised surfaces, and sharp edges. Feels like a real piece of machinery.
*   🌙 **Dark Mode ("CRT Command Center"):** Glowing phosphor screens with scanlines, CRT artifacts, and a deeply atmospheric dark UI.

## 🚀 Features

*   **Instant Generation:** Type or paste your URL/Text and watch the QR code generate in real-time.
*   **Immersive UI:** A completely bespoke, hand-crafted user interface with micro-animations, scanlines, and tactile responses.
*   **Fully Responsive:** Works seamlessly across desktop and mobile devices.
*   **High Quality:** Generates crisp, scannable QR codes ready for use.

## 💻 Tech Stack

*   HTML5 / Native DOM
*   Custom CSS Design System (CSS Variables)
*   Vanilla JavaScript

## 🚦 Getting Started

### Prerequisites

You need [Node.js](https://nodejs.org/) installed to run the local development server.

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/rubenvieira/qr-code-generator.git
   ```
2. Navigate into the directory:
   ```bash
   cd qr-code-generator
   ```
3. Install dependencies:
   ```bash
   npm install
   ```

### Running Locally

To start the local development server, run:

```bash
npm start
```

This will serve the static files on `http://localhost:3000`.

### Building for Production

To create a production build (copies static assets into a `dist` folder):

```bash
npm run build
```
